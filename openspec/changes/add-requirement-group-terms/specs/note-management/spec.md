# note-management

Requirement headings gain a Group Term. The four owner-scoped note operations are unchanged in wording
and in behaviour.

## RENAMED Requirements

- FROM: `### Requirement: A Registered User creates Notes`
- TO: `### Requirement: Create Note - A Registered User creates Notes`

- FROM: `### Requirement: A Registered User lists and reads only their own Notes`
- TO: `### Requirement: List Notes - A Registered User lists and reads only their own Notes`

- FROM: `### Requirement: An Owner updates their own Note`
- TO: `### Requirement: Update Note - An Owner updates their own Note`

- FROM: `### Requirement: An Owner deletes their own Note`
- TO: `### Requirement: Delete Note - An Owner deletes their own Note`
