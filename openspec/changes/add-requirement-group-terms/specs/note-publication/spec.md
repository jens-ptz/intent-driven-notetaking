# note-publication

Requirement headings gain a Group Term. The publication lifecycle and the anonymous feed are unchanged
in wording and in behaviour. `Read Public Feed` is shared with `web-client`, which specifies the same
operation from the browser.

## RENAMED Requirements

- FROM: `### Requirement: An Owner requests publication`
- TO: `### Requirement: Request Publication - An Owner requests publication`

- FROM: `### Requirement: An Administrator approves or rejects a Publication Request`
- TO: `### Requirement: Decide Publication - An Administrator approves or rejects a Publication Request`

- FROM: `### Requirement: Editing a published Note returns it to moderation`
- TO: `### Requirement: Re-moderate Note - Editing a published Note returns it to moderation`

- FROM: `### Requirement: A published Note can be withdrawn`
- TO: `### Requirement: Withdraw Note - A published Note can be withdrawn`

- FROM: `### Requirement: The Public Feed is readable without an Account`
- TO: `### Requirement: Read Public Feed - The Public Feed is readable without an Account`
