# note-tagging

Requirement headings gain a Group Term. Normalization, on-demand creation, whole-set replacement and
tag filtering are unchanged in wording and in behaviour.

## RENAMED Requirements

- FROM: `### Requirement: Tag input is normalized before lookup`
- TO: `### Requirement: Normalize Tag - Tag input is normalized before lookup`

- FROM: `### Requirement: Tags are created on demand and shared between Notes`
- TO: `### Requirement: Attach Tag - Tags are created on demand and shared between Notes`

- FROM: `### Requirement: Updating a Note replaces its whole Tag set`
- TO: `### Requirement: Replace Tags - Updating a Note replaces its whole Tag set`

- FROM: `### Requirement: Note lists can be filtered by Tag`
- TO: `### Requirement: Filter by Tag - Note lists can be filtered by Tag`
